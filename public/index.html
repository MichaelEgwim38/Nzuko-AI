Plug-and-play handover

What the group admin does

  1. Open the secure Nzuko AI link.
  2. Confirm that the group approved the pilot.
  3. Scan the WhatsApp Linked Devices QR with the approved account.
  4. Select only the approved WhatsApp group.
  5. Review each draft before anything is posted back to the group.

No code, Docker, server setup, or API keys should be handled by a normal group admin.

Privacy controls

Rules for the pilot

  • Only the approved group is processed.
  • Private chats are out of scope.
  • Voice notes are transcribed only with group consent.
  • Raw drafts can be cleared while approved minutes stay in the audit log.
  • Automatic posting stays off until the pilot proves trust.
